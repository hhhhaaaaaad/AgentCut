## 项目目标

AgentCut 面向短视频创作者，先聚焦单段口播/访谈素材的主题提炼：

```text
真实主视频 → 明确主题 → 多模态分析 → 合法片段决策
→ 七列时间轴剪辑脚本 → Java保存 → 前端查看/定位/导出
```

不把首阶段扩展为电影全片剪辑、复杂多素材叙事、爆款生成或一键高质量成片。

## 当前已知现状

- 三端已经存在：Java 后端、Python AI 服务、React 前端。
- Python 已有场景检测、抽帧、ASR/VAD、VLM、Timeline/Narration、导演、QA 和确定性校验。
- LangGraph 目前主要编排分析阶段，未配置持久化 checkpointer；Python job 状态在内存。
- 导演/QA 已有有限循环，但 QA 证据不完整，规则通过不等于语义完整。
- Java 已有 Task、Asset、Report、Plan、版本和 FFmpeg 渲染骨架。
- 默认内存仓储和本地文件存储；MySQL 实现存在但必须真实集成验证。
- 前端当前是上传、分析、编辑、预览导出四个页面，不要直接重写为超级组件。
- 工作区可能有用户既有未提交改动，禁止覆盖、回退或清理。
