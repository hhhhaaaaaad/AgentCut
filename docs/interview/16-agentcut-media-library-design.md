# AgentCut 视频包装素材库与 Agent 选材设计

日期：2026-10-17  
状态：待评审设计，不是已实现能力或实施授权。  
本轮只新增方案文档，不修改项目代码、不调用真实模型、不提交 Git。  
衔接：15-agentcut-timeline-script-design.md；不覆盖原脚本设计。

## 1. 目标与范围

在已有单段口播/访谈的剪辑脚本上，推荐来自授权素材库的补充画面、动画表情和过渡片段，帮助创作者减少寻找包装素材的时间。

保留一段主素材的主题与原声，包装素材是辅助，不扩展为复杂多素材故事编排。不宣称插入后一定更有趣、提升完播率或生成爆款。

首版交付：可预览的合法候选、推荐理由、插入位置与音画处理说明，写入七列剪辑脚本，由用户选择或拒绝。自动叠加、合成和转场渲染另外验收，不以已有 FFmpeg 能力推断这些已支持。

## 2. 三种路线

| 路线 | 机制 | 取舍 |
|---|---|---|
| A：标签规则推荐 | 类型/主题/风格过滤，固定规则排序 | 最简单，作为基线；隐喻和语境理解有限 |
| B：过滤召回 + Agent 比选 | 小库标签与关键词召回，Agent 阅读候选证据并选择 | 推荐；可解释、可控，可测是否优于 A |
| C：多模态向量检索 + 精排 | 视频/文本表征检索，必要时模型精排 | 库规模和检索失败证明需要后再引入，不默认复制 AgentWrite 的 RAG 栈 |

B 首版不要求向量数据库、独立推荐 Agent 或新的任务调度。复用导演的包装决策职责，通过受限素材检索工具获取候选。

## 3. 先区分“怎么插”

| 模式 | 例子 | 对时间与声音的影响 | 首版边界 |
|---|---|---|---|
| OVERLAY 叠加 | 问号动画、表情贴纸 | 在原画面上叠加，不延长主时间轴；默认素材静音 | 推荐并人工确认 |
| COVER_VIDEO 覆盖画面 | 讲“时间成本”时显示沙漏动画 | 暂时替换可见画面，主口播继续；总时长不变 | 推荐并人工确认，不删除原声 |
| INSERT_GAP 独立插段 | 章节之间插入 1 秒过渡片 | 增加成片时长，后续时间平移；默认放在可信语音边界 | 后续阶段，先做建议 |
| TRANSITION_EFFECT 转场效果 | 两段画面间溶解/擦除 | 属于编辑效果，不一定有素材文件；可能涉及重叠和可用余量 | 独立受限预设，后续验证 |

“转场片段”是库中的视频资产；“溶解转场”是效果预设，不能用同一种 assetId 混为一谈。透明动画遮住切口通常是 OVERLAY；满屏过渡也可 COVER_VIDEO，但必须说明口播是否连续。

第一版优先 OVERLAY/COVER_VIDEO：不改变主时间长度，更容易与原序原速脚本对账。叠加本身也不是当前已验证操作。

## 4. 素材入库与数据模型

### 4.1 入库流程

```text
上传授权文件
  → 检查授权/归属与访问权限
  → 文件类型、大小、时长、解码与安全检查
  → 元数据探测、缩略图/低清预览
  → 抽样帧/运动描述/声音摘要
  → 模型建议标签
  → 人工核对描述、语义和使用边界
  → 发布版本化素材
```

不从网络任意抓取表情包，不默认网络素材可商用。缩略图和预览由实际上传素材产生，不用生成图替代真实内容证据。

### 4.2 核心字段

| 类别 | 字段 |
|---|---|
| 身份 | libraryAssetId、assetVersion、contentHash、owner/tenant、visibility、status |
| 文件 | 可信 storageRef、mediaType、duration、尺寸、fps/时间基准、hasAudio、hasAlpha |
| 可用片段 | segmentId、start/end、verifiedDuration、可用循环范围 |
| 内容 | 实际画面/运动/声音描述、OCR/转写引用、关键帧引用 |
| 标签 | 主题、情绪、表达作用、风格、方向、语言、适用/禁用场景 |
| 兼容 | 可用模式、允许裁切/循环/变速、可放置区域和尺寸限制 |
| 授权 | 来源、许可证明、商业使用/修改/分发限制、署名要求、有效期 |
| 证据 | 描述来源、模型/人工核实状态、分析版本、失败记录 |

assetVersion 指不可变文件/描述快照；授权状态仍是实时准入条件，不能冻结旧快照绕过撤销或到期。资源下架后保留引用与失效说明，不能偷偷换成相似素材。

hasAlpha、loopSafe 等必须探测/核对，不能因为扩展名是 GIF/WebM 就认定透明或无缝循环。缺失描述可留在库中，但不作为自动推荐的可信候选。

## 5. Agent 如何推荐

### 5.1 先判断需不需要包装

输入：当前脚本行原文、叙事作用、相邻上下文、可见画面证据、风格与禁用要求、已用素材、时长/位置预算。

输出包装意图，例如：

- “补充说明重复劳动”，用于解释，而非替代事实证据；
- “强调疑问”，但不嘲讽受访者；
- “章节切换”，只在可信边界；
- NONE：原画面已能表达，或没有合适合法素材。

不按每行固定插入，不把库中已有素材反向强加到内容。

### 5.2 过滤与召回

先过滤访问权限、授权状态、已核实内容、模式兼容、画幅/透明要求、可用时长、声音策略及敏感限制；这些是硬条件，不由语义相似度抵消。

小库用人工核实标签、关键词和同义词召回，建议最多 5 个候选供比较。参数是实验配置，不是最佳值或性能成果。包含“不选择”，候选少时不强行凑齐。

如果发现主要失败来自同义表达漏召回，再测试文本 embedding；实际需要视觉相似检索时再考虑多模态 embedding。不能把向量分数当成编辑适配度。

### 5.3 比选与证据

Agent 只能选本次授权候选集中 libraryAssetId + assetVersion + segmentId，说明：

- 与哪句原文、哪个叙事作用匹配；
- 候选实际出现了什么，而不是只看文件名；
- 计划模式、锚点、时长、画面区域与原声策略；
- 哪些是情绪/风格判断，哪些有真实画面证据；
- 推荐和拒绝其他候选的原因。

动画应结合运动描述或连续帧/预览证据判断，不能单帧推断完整动作。证据不足降级为需人工试听/预览。

复用 QA 检查推荐是否误导、遮住关键画面、挤占字幕或带来风格冲突。模型评分只作诊断，用户确认前不视为已适配。

限制候选数、调用数和总预算，不无限反复搜库。无候选、超预算或模型失败时保留原脚本无包装版本。

## 6. 插入契约与时间计算

MediaPlacement 作为脚本 packagingSuggestions 的结构化扩展，不另建一套方案。

| 字段 | 规则 |
|---|---|
| placementId、scriptRevision | 唯一建议身份，绑定脚本快照 |
| assetRef + segmentRef | 版本化库资源引用，不允许任意 URL 或路径 |
| mode | OVERLAY/COVER_VIDEO；后续显式扩展 |
| anchor | rowId + unitId + 单元/行边界，程序映射输出位置 |
| duration/placementPreset | 来自可用范围及受限预设；程序验证 |
| audioPolicy | 默认 MUTE_LIBRARY_KEEP_PRIMARY |
| reason + evidenceRefs | 引用原文与素材证据 |
| status | PROPOSED/ACCEPTED_MANUAL/COMPILED/REJECTED |

程序根据锚点算最终 outputRange，模型不提交自由成片时间。暂无词级对齐时不声称精确落在某个关键词上；可选可信行起点，或标记人工调点。人工位置调整以受限编辑保存，校验是否仍落在有效锚点范围。

OVERLAY/COVER_VIDEO 必须位于所锚定的行内，首版不跨行；素材太短不擅自循环/拉伸，只有经核实且许可允许的预设才能使用，否则换候选或放弃。太长则引用库中已核实的可用片段。

未来 INSERT_GAP 会增加时长；TRANSITION_EFFECT 由预设定义重叠/句柄规则。两者通过时间编译器重算字幕、后续锚点和总时长，不沿用原脚本简单累计公式。超上限返回冲突，不删原口播给包装让位。

图层次序和位置采用有限预设。画面底层、包装层、字幕层明确；指定字幕安全区，检测人物/关键示意区域未知时只建议人工放置，不宣称自动遮挡检查已准确。

## 7. 写入七列脚本的例子

以下资源、时间和内容均为虚构示意，不代表已有库或真实执行。

| 镜号 | 成片时间 | 原素材入点—出点 | 画面 | 原声／声音 | 字幕与包装 | 剪辑备注 |
|---|---|---|---|---|---|---|
| 03 | 00:16–00:30 | 01:15–01:29 | 原采访；在本行起点覆盖 2 秒“人物关系箭头”动画 | 原采访原声连续，库动画静音 | `relation_arrow@v1/seg1`，COVER_VIDEO，00:16–00:18，待确认；原声字幕保留 | 用于说明指代关系，不暗示动画人物是真实当事人；未自动执行 |
| 04 | 00:30–00:44 | 02:06–02:20 | 原采访；左上角叠加 1 秒思考符号 | 原声保留，素材静音 | `thinking_icon@v2/seg1`，OVERLAY，00:30–00:31，待确认 | 不遮挡字幕；没有关键词对齐，使用行起点，用户可调 |

表外素材清单给出预览、资源版本、截取范围、许可/署名、使用模式、推荐理由、替代候选和执行状态。

主素材原区间仍保持原序；覆盖/叠加使用附属轨，不把辅助动画混进原声转写。独立插段后续加入时要显式列成脚本行，原素材列写库资源入出点，原声列写真实声音策略，不能留空隐藏时长。

## 8. 工程职责与现有边界

- Java：素材元数据、权限/授权、可信存储引用、版本、最终推荐准入和脚本保存；复用现有任务体系处理入库分析。
- Python：素材描述/标签建议、检索意图、候选比较与语义风险，不直接下载任意 URL 或输出执行命令。
- React：素材预览、替换/拒绝、不插入、插入理由与许可提示、脚本版本编辑。
- 存储：复用或扩展实际文件存储，预览与原件区分。既有 MinioStorage 名称不代表已有 MinIO 接入；跨服务文件访问另按部署方案核实。
- 渲染：当前 Plan 1.0 单 source + 段内操作不能表达附属素材轨。首版保留 ACCEPTED_MANUAL，不伪映射成现有 subtitle/crop；自动合成需要显式的新契约/编译能力。

不同时引入向量库、消息系统、复杂轨道编辑器与新 Agent 框架。

## 9. 风险与异常处理

| 情况 | 行为 |
|---|---|
| 无适合素材 | NONE，保留原片；记录无匹配原因 |
| 非授权/越权资源 | 入候选前排除，确认与下载再次检查 |
| 授权到期、下架 | 建议失效，提示替换；旧版本不绕过当前准入 |
| 未核实声音/动画内容 | 人工预览，不默认静音就消除全部风险 |
| 表情暗示嘲讽、改变立场 | QA 告警，保守拒绝或人工处理 |
| 示意画面被误当事实 | 标明示意；敏感语境禁用，不以素材增强不存在的事实 |
| 用户修改行/索引 | 重算锚点，重新审查语义；建议未确认，旧确认失效 |
| 遮挡主体/字幕或重叠拥挤 | 换预设或放弃，不强行叠加 |
| 原素材时长已用满 | 不插新增时长的过渡段，不擅自加速或删原声 |
| 未支持渲染模式 | 可输出人工脚本，不标 executionReady |
| 模型返回外部路径/未知资源/命令 | 拒绝，限于候选资源与白名单参数 |

上传处理限制大小、分辨率、时长与解码资源，拒绝可执行内容/未支持格式；媒体解析隔离、文件路径受控。素材字幕/OCR/文件名为不可信内容，不能变成系统指令。

预览与导出权限分开；若分发原文件违反许可，只交付引用或允许的访问方式。许可不清的素材不能进入首版可用库。

## 10. 分阶段与验证

| 阶段 | 内容 | 验收 |
|---|---|---|
| L0 | 建议 20～30 个自制/授权素材，人工核实描述和限制 | 每个候选可播放、可追溯、权限明确；规模仅为实验建议 |
| L1 | 标签/关键词基线 + Agent 比选，七列脚本推荐 | 无未知/越权资源；有理由、预览、锚点、NONE 与降级 |
| L2 | 人工选择/替换、版本绑定、导出资源清单 | 脚本改动建议失效；时间一致；人工与机器状态不混淆 |
| L3 | 单一模式自动合成试点，再扩展其他模式 | 真实音画/时长/遮挡对账；不承诺一次支持所有包装 |

首个最小闭环 L0～L2；L3 不默认进入实施。

确定性测试：非法 asset/version、租户越权、授权撤销、缺 alpha/音轨信息、素材不足长、锚点过期、超行边界、字幕遮挡区域、未知操作、未支持模式、重复/晚回调。

效果对照：相同脚本与素材库，对比人工找素材、标签规则推荐、Agent 比选；ASR 文本与视觉证据增益按需消融。

主要指标：

- 候选可用/适配情况：人工判断是否表达目标、风格合适、不误导；允许多种合理答案，不硬规定唯一正确素材。
- 检索覆盖：人工认可的可用素材是否进入候选；与最终选择质量分开。
- 用户收益：寻找时间、预览数量、替换/拒绝次数、最终采用率；采用率不等同质量。
- 内容风险：误导、情绪冲突、遮挡和原声受损，失败样本保留。
- 工程：非法引用/授权违规、锚点错误、模式不支持、总耗时、模型调用成本及降级。

小规模真实任务、素材与模型版本冻结、盲评推荐来源，记录用户先后顺序。没有合适素材的任务也纳入，防止用强行插入提高采用率。先报告逐样本数据，不预设提升数字。

## 11. 面试表达与待确认

业务问题：剪辑脚本确定后，创作者仍要花时间寻找匹配的包装素材。  
设计取舍：先用授权与媒体条件过滤，再让 Agent 结合原文和真实预览证据选材，引用合法版本 ID，不任意生成资源。  
异常边界：允许不插入，保留主原声，不把示意素材当事实，不把人工建议当已渲染。  
验证结果：实施后填写实际选材时间、适配风险、成本和对照收益。

本轮建议的首版范围：小型授权库、OVERLAY/COVER_VIDEO 推荐、人工确认；独立插段、转场效果和自动合成后续单独验证。用户需确认该范围后才进一步细化实施，当前所有新增能力不能作为已完成简历成果。
