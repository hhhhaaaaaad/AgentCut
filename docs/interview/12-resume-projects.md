## 项目一：AgentWrite

```
AgentWrite | AI 多智能体个性化创作工作台 | 个人项目 · 独立开发 | 2026.06 – 2026.08

技术栈：Spring Boot 3 / Java 17 / Google ADK / Qdrant / RocketMQ / Redis / MySQL / React
GitHub：https://github.com/hhhhaaaaaad/AgentWrite

项目背景与目标：
面向技术创作者的 AI 写作工作台，支持草稿续写、质量审校与智能配图。核心解决
LLM 应用落地的两个工程难题：无状态（跨会话个性化）与长任务可靠性（异步执行）。

核心工作：
1. 【个性化记忆系统 · 含评测平台】设计记忆「抽取 → 存储 → 混合检索 → 注入」全链路：
   LLM 从历史会话抽取用户技术背景与写作偏好，LLM + Hash + 向量相似度三层去重；
   Qdrant 向量 + BM25 关键词 + 画像缓存融合评分 + Reranker 精排，长期记忆动态注入 Prompt。
   配套独立搭建记忆评测平台（Python/FastAPI）：五维度评测（抽取/检索/注入/治理/一致性），
   config_fingerprint 保证评测可比性，mutation 测试验证评测本身可信。

2. 【长任务异步可靠性】基于 RocketMQ 构建异步写作任务机制，任务提交与 Agent 执行解耦；
   Transactional Outbox 保证任务与事件一致，任务抢占 + 状态流转避免重复执行，
   心跳 + 恢复保证可靠性，支撑长耗时 AI 创作任务稳定运行。

3. 【多智能体编排】基于 Google ADK 构建 Multi-Agent 编排框架，将模型、Prompt、Skill、
   工具及工作流配置化；设计 Planner-Generator-Enforcer 链路，规则约束文章格式。
```

## 项目二：AgentCut

```
AgentCut | AI 视频智能剪辑平台 | 个人项目 · 独立开发 | 2026.08 – 2026.10

技术栈：Python / FastAPI / LangGraph / VLM / FunASR / PySceneDetect
GitHub：https://github.com/hhhhaaaaaad/AgentCut

项目背景与目标：
面向视频剪辑的 AI 半自动化剪辑平台，核心解决 LLM 应用的能力边界扩展——
从文本到视频的多模态理解。

核心工作：
1. 【多模态视频理解】构建视频分析链路：VLM 视觉理解 + ASR 语音转写（VAD 分割）+
   场景检测 + 动态抽帧，提取带时间戳的章节、关键句与冗余片段。

2. 【多 Agent 脚本生成与可控性】分析专家、导演、质量监督三 Agent 协作生成剪辑脚本，
   质量监督五维评分 + 迭代重写，12 条校验规则 + 关键场景兜底恢复，
   解决大模型直出剪辑脚本不可控的问题。
```

## 面试话术：成片效果不好怎么答

AgentCut 的自动成片质量暂不理想，简历上已弱化（只字不提 FFmpeg 渲染细节）。若被问
「成片效果怎么样」，诚实 + 转化为加分：

> 「自动成片目前的质量还不理想，主要卡在导演 Agent 的删减决策上——容易把关键片段误删。
> 我已经定位到这个点，做了『必须保留规则 + 删减预算』的确定性兜底。这也让我意识到
> LLM 输出的可控性必须靠规则兜底，不能全靠模型自觉。」

对应提交：`ab340c6 feat: 导演删减决策优化`——「效果不好但我知道哪里不好、且已在改」，
是成熟度而非短板的体现。
